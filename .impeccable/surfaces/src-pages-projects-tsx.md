# Inspectable project work

Mode: Experience. Lead with the actual project, its published command, repository and supporting case-study evidence. The owner requests more life and interaction inside the approved visual world. Keep both published projects and their factual copy.

Use flat outlined project panels that pair summary and code on desktop and stack on narrow screens. Copy command confirms copying only; it never executes. The case-study toggle animates disclosure, retains direct hash links, and keeps collapsed material out of focus order. Color fades and directional link feedback supply a coherent rhythm. Preserve code/technical overflow locally and honor reduced motion.
